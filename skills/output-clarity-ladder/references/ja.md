# 出力の明確さラダー（日本語）

この文書は ASD-STE100 の考え方を使います。ASD-STE100 の認証文書ではありません。This text applies ASD-STE100 principles and is not ASD-STE100 conformant. 承認済み語彙のチェックはありません。

説明、要約、教える返信のたびに使います。一行の状況、はい／いいえ、ユーザーが自分で書くと決めた下書きは、求められた形のままにします。

## 1. 文章（既定）

- ユーザーの言語を使います。技術名は通常の形のまま残します。
- 一文に一つの内容を書きます。短い文と能動態を使います。
- 動作の主語を書きます。
- 一つのものに一つの語を使います。同じ物を別の語で言い換えません。
- 数字、条件、不確かさを残します。簡単に見せるためだけに事実を削りません。
- 認証済みの ASD-STE100 と主張しません。

## 2. 図

構造、流れ、比較が要点のときは、長い段落の代わりに図を付けます。

## 3. Webページ

ユーザーが調べる、再利用する、保存するときは、単独で動く HTML ページを作ります。確認に役立つときだけ操作機能を使います。

## 4. 解説動画

ユーザーが見たい、聞きたいと言ったとき、または音声付きの映像が文章より明らかに分かりやすいときだけ、短い解説動画を作ります。通常の返信では動画を作りません。ナレーションには、ユーザーが保存済みのキーか、無料のローカル機能を使います。シークレットをチャットに貼るよう求めてはいけません。

## Order

最初は文章です。次の形式が同じ事実をより分かりやすくするときだけ、上の段に進みます。求められた成果物（メール、履歴書、コード）を別の形式に置き換えません。
