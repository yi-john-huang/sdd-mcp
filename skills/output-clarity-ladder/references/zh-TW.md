# 輸出清晰度階梯（繁體中文）

本文件採用 ASD-STE100 的原則。本文件不是 ASD-STE100 認證文件。This text applies ASD-STE100 principles and is not ASD-STE100 conformant. 沒有核准詞彙檢查。

每次說明、摘要或教學回覆都使用本文件。一行狀態、是或否、使用者要自己措辭的草稿，維持使用者要求的形式。

## 1. 寫作（預設）

- 使用使用者的語言。技術名稱保持常見寫法。
- 一句只寫一個重點。使用短句和主動語態。
- 寫明誰執行動作。
- 一個東西只用一個詞。不要用同義詞替換同一個物件。
- 保留數字、條件和不確定性。不要只為了顯得簡單而刪掉事實。
- 不要宣稱文字通過 ASD-STE100 認證。

## 2. 圖表

重點是結構、流程或比較時，用圖表取代長段落。

## 3. 網頁

使用者要探索、重複使用或保存結果時，製作獨立的 HTML 網頁。只在有助於檢查想法時才加入互動。

## 4. 說明影片

只在使用者要求觀看或聆聽，或有旁白的畫面明顯比文字容易理解時，才製作簡短的說明影片。一般回覆不製作影片。旁白使用者已儲存的金鑰，或免費的本機方案。絕不要求使用者把機密貼到聊天中。

## Order

從寫作開始。只有下一種形式能讓相同事實更容易理解時，才往上一階。不要用其他形式取代使用者要求的成品（電子郵件、履歷、程式碼）。
