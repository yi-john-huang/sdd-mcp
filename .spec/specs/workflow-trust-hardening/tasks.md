# Tasks: Workflow Trust Hardening

## Overview

The tasks run in five groups. Machine checks come first, so all new code is written under strict TypeScript and the lint ratchet. Engine foundations come next, then the engine gates, then Skill and asset text, then documentation and final verification. Every behavioral task starts with a failing test (RED). Each P0 bypass test is run against the 6.0.0 engine code first and must fail, which proves the bypass existed.

All tasks run in sequence in the parent. Verified evidence runs only at the project root, so this feature uses no parallel slices.
